# 竞品分析


## 一、核心字段定义库（分析前的必修课）

| 字段名称 | 定义与分析价值 |
| :--- | :--- |
| **ASIN** | 亚马逊标准识别号，竞品的唯一身份ID。 |
| **月销量** | 核心指标。判断市场需求强度的**第一关键指标**，决定赛道容量。 |
| **大类BSR** | 大类目排名。用于**竞品竞争力分层**（数字越小，竞争力越强）。 |
| **小类目** | 产品所在最细分的节点。**精准定位直接竞争对手**的关键。 |
| **小类BSR** | 小类目排名。衡量产品在细分赛道的表现。 |
| **月销售额($)** | 结合月销量和价格，判断竞品的**营收规模和资金效率**。 |
| **评分数** | 用户口碑和流量基础的体现，反映产品的**长期竞争力**。 |
| **月新增评分数** | **流量和转化效率的“晴雨表”**。估算公式：（评分数 / 上架天数）* 30。若表格直接提供，则直接使用。 |
| **留评率** | （评分数 / 月销量）* 100%。衡量用户**评价积极性**，反推产品质量和买家体验。 |
| **价格($)** | 核心运营策略。直接决定**转化率和利润空间**，用于对标定价。 |
| **Coupon** | 促销手段。分析类目**促销渗透率**，寻找差异化机会。 |
| **毛利率** | 盈利能力的直接体现。**筛选高利润对标对象**，判断成本优化空间。 |
| **FBA费用($)** | 物流核心成本。与**包装尺寸分段**强相关，是利润优化的关键抓手。 |
| **上架天数** | 判断产品生命周期（新品/成熟品/老品），**对标推广节奏**，也是判断“近期切入”的核心依据。 |
| **BuyBox卖家** | 赢得购物车的卖家。**统计卖家归属地**，优先对标中国卖家。 |
| **卖家数** | 该ASIN的跟卖数量。结合BuyBox数据，判断**Listing控制力**。 |
| **包装尺寸分段** | **物流成本的决定性因素**。小号标准尺寸的FBA费用远低于大号标准尺寸，是利润差异的关键来源。 |

## 二、完整五步闭环分析流程（V2.0）

### **步骤1：锁定1个核心分析目标（聚焦，避免发散）**

从业务需求出发，三选一，确保所有分析都围绕这一个目标展开：
*   **目标A - 产品机会挖掘：** 寻找“月销量高 + 毛利率高”的蓝海细分赛道。
*   **目标B - 运营策略对标：** 参考头部/腰部竞品的“价格、Coupon、Listing”策略，优化自身。
*   **目标C - 盈利优化：** 分析高毛利率竞品的“成本结构（FBA、尺寸）+ 定价”，提升自身利润。

> **【本次示例目标假设】我们继续选择目标C：盈利优化，并同时关注目标A（机会挖掘），通过“竞品扩张动向”辅助判断新赛道。**

---

### **步骤2：筛选3-5个核心对标竞品（精筛，确保价值）**

从表格中，按以下四个维度严格筛选：

1.  **类目完全匹配：** 仅保留与自身产品**小类目完全一致**的竞品。例如，若你做的是“Women's T-Shirts”，就只筛选小类目为“Women's T-Shirts”的ASIN。
2.  **数据完整：** 筛选“月销量、毛利率、评分数、价格、FBA费用、包装尺寸分段”无缺失的竞品。
3.  **卖家归属地聚焦：** **优先筛选`BuyBox卖家`为中国（CN或CN(HK)）的竞品**。他们的运营逻辑和成本结构与你最相似，参考价值最高。
4.  **竞争力分层覆盖：** 按“大类BSR”排名，至少选取两类：
    *   **头部竞品（1-2个）：** 大类BSR排名前20%（如BSR<200），看行业标杆。
    *   **腰部竞品（2-3个）：** 大类BSR排名在30%-60%（如BSR在300-800），看可直接追赶的对手。

### **步骤4：15个可量化指标深度分析（新增“竞品扩张动向指标”）**

围绕“盈利优化+机会挖掘”目标，对数据进行五类指标分析：

#### **1. 需求强度指标（判断市场潜力）**
*   **小类目月销量中位数：** 计算同小类目竞品月销量的中位数，避免头部爆款造成的“虚假繁荣”。
*   **BSR-销量关系：** 观察BSR排名与销量的关系，判断流量集中度。

#### **2. 流量与转化指标（判断流量质量）**
*   **月新增评分数排名：** 识别当前流量增长最快的竞品。
*   **留评率：** 对比类目均值，判断用户评价积极性。
*   **BuyBox占有率：** 结合卖家数，判断Listing控制力（本数据集中所有竞品均为1个卖家+FBA，说明FBA是赢得BuyBox的前提）。

#### **3. 运营策略指标（对标运营动作）**
*   **价格竞争力：** （竞品价格-同小类均值）/同小类均值。
*   **Coupon设置率：** （设置Coupon的竞品数/同小类总竞品数）×100%。**本数据集中为0%，是差异化突破口。**
*   **FBA配送占比：** **本数据集中为100%，FBA是入场券。**
*   **上架天数分层：** 新品（＜90天）、成熟品（90-365天）、老品（＞365天）。

#### **4. 利润与风险指标（判断盈利可行性）**
*   **毛利率分层与FBA费用关联分析：** 重点分析高毛利竞品的尺寸分段，发现**小号标准尺寸是获取高毛利的关键**。
*   **卖家竞争强度：** （同小类竞品的卖家总数/小类商品数）×100%，估算类目拥挤度。

#### **5. 【新增】竞品扩张动向指标（判断卖家最新布局）**
| 指标名称 | 计算逻辑 | 可量化评估标准 |
| :--- | :--- | :--- |
| **新品切入类目热力图** | 筛选**上架天数 < 90天**（可根据需要调整为60天或180天）的ASIN，统计每个小类目下的ASIN数量，并计算这些新品的平均月销量、平均毛利率。 | • **热点类目：** 某小类目下新品ASIN数量 ≥ 3，视为近期卖家集中切入的赛道。<br>• **潜力新品：** 若某新品月销量 > 该类目整体平均月销量的1.5倍，且毛利率 > 30%，则为高潜力竞品，需重点追踪其动态。<br>• **卖家扩张路径：** 若同一卖家在多个小类目均有新品上架，说明该卖家正在实施多品类扩张，可研究其产品线逻辑。 |

> **【基于你表格数据的示例计算】**
> *   设定新品标准：上架天数 < 200天（因为表格中最新的ASIN上架天数为198天）。
> *   筛选出新品：B0F5978RKM（249天，略超，但可调整阈值）、B0F66V9SXS（253天）、B0FBFBK7RJ（198天）、B0DHWZCZ37（445天，不算）、B0DK3K9WRV（450天，不算）……实际应重新计算。假设我们严格按<200天，则只有B0FBFBK7RJ（198天）属于新品，它的小类目是“Women's Casual Pants & Capris”。
> *   **分析结论：** 近期（近200天）仅有一个新品切入“女式休闲裤”类目，且该ASIN月销量15928，毛利率65%，表现亮眼。这说明卖家正在向“裤子”品类扩张，且取得了初步成功。若该卖家是PRETTYGARDEN（同一品牌），则表明该品牌正在从上衣向裤子延伸，值得关注其后续动作。

### **步骤5：可落地策略输出（数据支撑，行动导向）**

基于以上五类指标分析，围绕“盈利优化+机会挖掘”目标，输出具体策略：

1.  **产品开发策略（对标黄金样本+热点类目）：**
    *   **硬性指标：** 新品开发优先控制包装尺寸至“小号标准尺寸”，力争FBA费用低于4$，对标B0F66V9SXS的利润模型。
    *   **热点类目跟进：** 若“新品切入类目热力图”显示某小类目近期新品密集（如≥3个），需评估该赛道是否已变红海；若只有零星新品但表现优异（如B0FBFBK7RJ），则说明该赛道仍有空间，可快速跟进类似产品。

2.  **运营推广策略（利用数据空白）：**
    *   **Coupon测试：** 鉴于主类目Coupon渗透率为0%，新品上线立即设置5%-8% Coupon，测试拉新效果。
    *   **评论激励：** 针对低留评率，设计“留评引导卡”，加速评论积累。

3.  **利润优化策略（组合拳）：**
    *   **定价策略：** 避免低价泥潭，参考B0F66V9SXS，若有差异化卖点，可定在20-25$价格带，并用Coupon弥补初期劣势。
    *   **FBA成本复盘：** 极致压缩包装，力争“小号标准尺寸”，直接提升利润率。

4.  **竞品追踪策略（动态监控）：**
    *   **建立监控列表：** 将“新品切入类目热力图”中识别出的高潜力新品（如B0FBFBK7RJ）加入每日监控，关注其排名、价格、Coupon变化，及时应对。
    *   **卖家扩张预警：** 若发现同一品牌（如PRETTYGARDEN）在多类目密集上新品，需警惕其可能成为全品类 competitor，提前规划差异化卖点。
