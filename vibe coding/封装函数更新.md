根据用户指定的py文件，生成一个Excel表格，要求如下：

1. 提取该文件中所有函数定义（def关键字后面）的参数信息
2. 每个参数单独占一行
3. 表格包含以下列：
   - 函数名称
   - 参数名称
   - 替换参数名称（空白列，供填写）
4. 保存到 `[输出Excel路径]`

示例格式：
# boston2
| 函数名称 | 参数名称         | 替换参数名称 |
|----------|------------------|--------------|
| boston2  | df               |              |
| boston2  | x_axis_col       |              |
| boston2  | y_axis_col       |              |
| boston2  | product_name_col |              |
| boston2  | chart_width      |              |
| boston2  | chart_height     |              |
| boston2  | font_name        |              |

# boston3
| 函数名称 | 参数名称         | 替换参数名称 |
|----------|------------------|--------------|
| boston3  | df               |              |
| boston3  | x_col            |              |
