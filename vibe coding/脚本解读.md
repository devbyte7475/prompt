# 约束（硬性不可违背，全部满足，核心约束置顶加粗，优先级最高）
1. **核心第一约束（绝对遵守，重中之重）**：解析文档内**全程无任何代码、无任何代码块、无任何编程语言的语法符号、无任何代码片段粘贴**，所有代码相关的内容，必须100%通过精准、完整、无歧义的中文文字进行描述和表达，把代码的全部内容与逻辑彻底转化为文字形式，这是本次解析的核心硬性要求，无任何例外。
2. 内容约束：解析内容100%忠于原脚本源码，**不增删、不篡改、不曲解**原脚本的任何逻辑、代码、功能，所有解读均基于原脚本本身，无主观添加的内容，文字描述的每一个逻辑点都与原脚本完全对应。
3. 逻辑约束：脚本的执行流程、分支判断、循环规则、异常处理等核心逻辑，文字解析必须做到「精准无偏差」，哪怕是一行代码的注释含义、一个参数的默认值、一个条件判断的符号逻辑，都要用文字准确无误的表述出来，这是复刻的核心前提。
4. 细节约束：不放过任何细节，包括但不限于：脚本中的注释含义、代码段落的分隔逻辑、变量命名的意图、函数的调用顺序、依赖包的版本隐性要求、特殊场景的兼容逻辑，全部用文字完整表述，无任何细节遗漏。
5. 语言约束：通篇使用「精准、简洁、无歧义的中文」，技术术语使用规范，解读通俗易懂，无冗余废话、无模糊表述（如“大概”“可能”“或许”），所有表述均为确定性结论，文字描述的逻辑能让任何人/AI都能精准理解代码本意。
6. 适配约束：解析文档的Markdown结构，需适配所有AI模型的读取和理解能力，无复杂嵌套、无特殊符号、层级清晰，纯文字排版，便于AI识别、理解并精准复刻脚本。
7. 完整性约束：无论脚本长短、逻辑简单或复杂，均按上述全部解析要求完成，不因为脚本简短而省略解析维度，不因为脚本复杂而删减关键细节，所有代码逻辑都必须完整文字化。
